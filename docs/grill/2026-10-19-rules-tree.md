## Recon (что было известно до первого вопроса)

- Библиотека дефектов (`docs/defects/`, ADR-014, v0.19): карточка на класс, секции `## Never` (= запреты) и `## Allowed` (= разрешения), цитаты владельца дословно, `check:` + фикстуры, гейт долга `scripts/defects-check.sh`. — файлы
- Доставка: `defects-inject.sh` (PreToolUse) толкает Never-строки по `paths:`; `defect-intake.sh` (UserPromptSubmit) — подсказка «похоже на поправку», ничего не пишет. — файлы
- `.claude/rules/` — path-правила, грузятся при чтении файла; без `paths` грузятся всегда (docs/en/memory). — файлы + docs
- ADR-019: без векторов, БД, per-prompt recall, саморедактирующегося CLAUDE.md, общей памяти между проектами; урок принимается как проверка, не проза. — файл
- Размер библиотек по ульям: VULYK 12 карточек / 579 строк; ~15 ульев 6–15 карточек; самый большой (видео-улей) 54 карточки / 3 051 строк + 825 строк path-правил. — замер
- Приватная auto memory Claude Code: 9 проектов по 75–273 файла, 2,2–12,8 тыс. строк, 47–140 `feedback`; индексы MEMORY.md 20–46 KB. Claude Code грузит первые 200 строк или 25 KB индекса, topic-файлы при старте не грузятся. — замер + docs/en/memory (2026-10-19)
- Выборка 36 feedback-памятей: ~60% правила проекта «как надо», ~22% дубли общих карточек VULYK, ~14% личное (люди, общение с владельцем); почти нет дословных цитат владельца. — замер
- litopys 0.4.1: журнал сессий, `## Corrections` с дословной проверкой цитат, `litopys corrections`, recall. Описательная память; VULYK — предписывающая (ADR-014). — README/CHANGELOG
- Вставленный текст (`<pasted_content>`) режут и intake VULYK (`defect-intake.sh` BLOCKS), и litopys (`raw-journal.sh` → `## notice`). Голосовая вставка владельца не считается его словами ни там, ни там. Intake при этом сработал на неразмеченную заметку модели. — файлы + эта сессия

## Synthesis (final, 2026-10-19)

1. **Verdict.** Новая библиотека не строится. Библиотека дефектов `docs/defects/` становится деревом правил проекта: папки по областям, в карточке три ветки (Нельзя / Можно / Как надо), область = пути + команды + инструменты. Повтор записанного становится видимым и редким: по запретам и правилам — красный гейт до проверки кодом, по разрешениям — счётчик. Захват слышит владельца во всех каналах (набранный текст, вставки через «да» или явную фразу, ответы в окнах), пишет сразу дословно и отчитывается строкой. Приватная память разбирается разово: проектное — в карточки, личное — остаётся; новый поток туда перекрыт строкой конституции и глобальным правилом. litopys — дословная история и недельная страховка, необязательный, в карточки не пишет.
2. **Decision log** — D1–D12 в Ledger выше, плюс D13 перенос: разовый разбор по ульям, пакетом, без фальшивых цитат (Q18); D14 поток: строка конституции + глобальное правило владельца (Q19); D15 раскатка: пилот на 2 ульях ~неделю, потом все (Q20).
3. **Assumption ledger.**
   - ✓ PostToolUse-хук с matcher `AskUserQuestion` получает `tool_response.answers` {вопрос: ответ} и `tool_input` с вариантами — проба 2026-10-19 в этой сессии (временный хук в settings.local.json, подхвачен на лету). ⚠ Дописанный текст: в пробе владелец текст не вписал; форма выведена из ответа на Q1 этой сессии (варианты + свободный текст в кавычках через запятую) — дописанное = части ответа, не совпадающие ни с одной меткой варианта.
   - ✗ Короткая вставка из программы диктовки тоже приходит как pasted_content — перенесено в пилот; не блокирует: незавёрнутая вставка уже читается как набранный текст.
   - ✗ Доля проектного в приватной памяти ~80% — выборка 36 из 3 проектов; пилот даст полную цифру.
   - ✗ Найденный случай — тот же класс, что «три дня назад»: порядок дат не сверен.
