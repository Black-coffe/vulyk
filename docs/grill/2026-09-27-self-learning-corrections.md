Код гейта — обычная Tier 1 работа VULYK с одним ревью. — design

Q14 (D2): Миграция накопленного?

Одним диффом на одобрение владельца. — design
Q15 (D5): Критерий «работает / выключаем»?

Успех за 4 недели на пилотах: гейтовые — 0 повторов, текстовые — вдвое меньше базы, инъекции ≤ 1% токенов сессии. ## Synthesis (2026-09-27)

### Вердикт
Урок про хвост речи в YouTube_AI записался и был разложен по категории. Три ролика подряд провалилось его применение: текст в path-scoped правиле грузится только на Read и исчезает после компакции. Сам урок требовал проверку в коде, но так и остался прозой. Самообучение VULYK строится вокруг применения, а не захвата. Возражение ловит regex-хук UserPromptSubmit ($0), судит сама сессия. Проверяемый запрет в той же сессии становится гейтом: warn → block, две фикстуры из реального случая, прогон по истории. Непроверяемый становится строкой в дереве запретов в git хоста; личные запреты — в дереве ~/.claude. Строку толкает хук PreToolUse/UserPromptSubmit перед действием ветки (≤ ~1000 токенов, раз за сессию и после компакции). Триггеры ветки берутся из путей и команд, которые реально были в ходе ошибки. Повтор считается инцидентом носителя: чинится гейт или носитель поднимается на ступеньку, текст громче не делается. Снятый запрет отзывается с причиной. Пункты сливает скрипт по id (не модель).
