# Scout report: scripts/, tests/, .github/workflows/ci.yml

## Purpose
Deterministic (model-free) gate scripts implementing VULYK's cycle (docs/cycle.md): scope, wave, trace, acceptance, human, ship checks, plus state derivation and top-model resolution. tests/ exercises the cycle gates and the handoff context-window resolver; CI wires both plus inline smoke tests.

## Entry points
- `scripts/ship-check.sh` — stage gate over all 6 confirmations; `--record` closes stage 06.
- `scripts/acceptance-log.sh` — stage 04 ledger (blind gate verdict); `--check` for staleness.
- `scripts/human-check.sh` — stage 05 ledger (owner verdict); `--check` for staleness.
- `scripts/state.sh` — derives gitignored `.claude/state.json` from story frontmatter + plan.md markers.
- `scripts/wave-check.sh` — pre-dispatch story sanity (collisions, order, missing paths, verify-gap).
- `scripts/trace-check.sh` — brief.md ↔ story `## Requirements` quote tracing.
- `scripts/scope-check.sh` — declared vs. actually-changed files per story.
- `scripts/release-check.sh` — counts specs meeting 1.0.0 criterion (1).
- `scripts/top-model.sh` — resolves fable/opus from `~/.claude.json` plan signal; `--apply` pins it.
- `tests/cycle.test.sh` — full synthetic walk of ship-check.sh/human-check.sh through all 6 stages.
- `tests/handoff-window.test.py` — matrix test of `.claude/hooks/handoff.py` context-window math (not part of the 6 questions but is the only other tests/ file).

## Key types / contracts
- **`pack_fingerprint(spec-dir)`**: sha256 (first 12 hex chars, `shasum` fallback, else `n<count>`) over sorted basenames of `*.md` files carrying `^story:` frontmatter. Duplicated verbatim in ship-check.sh:21-37, acceptance-log.sh:41-57, human-check.sh:27-43, release-check.sh:41-57 — comments in each say "must match ... exactly." Identifies *which stories*, not their content.
- **`paperwork_only(root, from, to)`**: duplicated in ship-check.sh:42-56 and human-check.sh:49-63. A commit range is paperwork-only iff every changed path matches `*/plan.md | memory/stats/human.jsonl | memory/stats/acceptance.jsonl | memory/stats/ship.jsonl`.
- **`marker(plan.md, Name)`** (ship-check.sh:59-64): `grep -m1 "^\*\*Name:\*\*"`, value is empty/absent if unset or starts with `<` (template placeholder).

## Dependencies
All scripts: `set -u`, POSIX-ish bash, `git`, `awk`, `sed`, `grep`; `sha256sum`/`shasum` optional. `top-model.sh --apply`'s merge path needs `python3`/`python`/`py`. Exit status is always 0 for every gate script (they report, never block) except `top-model.sh --check` (0/1) and `top-model.sh --apply` (1 if no Python and file exists).

## Gotchas
- Glob/Grep tools returned empty for every directory-level query in this session (even `Glob("*", path="E:/Projects/vulyk")`); only exact-path `Read`/`Grep-on-one-file` worked. I could not do an authoritative directory listing — I confirmed `tests/` contents by probing plausible filenames (wave-check.test.sh, trace-check.test.sh, scope-check.test.sh, top-model.test.sh, install.test.sh, release-check.test.sh, tests/README.md) and all came back "File does not exist," leaving `cycle.test.sh` + `handoff-window.test.py` as the only two — high confidence, not proof.
- ship-check.sh's `marker()` covers **Approved**, **Branch**, **Shipped** only — it never reads the **Checked:** line itself; stage 05 comes entirely from `memory/stats/human.jsonl`. state.sh, separately, greps `**Checked:**` directly (its own local `mark()` covers Approved/Branch/Shipped; Checked is a bespoke grep).
- `acceptance-log.sh --check` only ever says CURRENT or STALE (pack) — it has no commit-based staleness check. Only `human-check.sh --check` distinguishes STALE (pack) vs STALE (commit); that asymmetry is real, not an oversight I should smooth over.

## Answer

**1. ship-check.sh markers.** `marker()` (ship-check.sh:59-64) does `grep -m1 "^\*\*$2:\*\*" plan.md | sed 's/^\*\*$2:\*\*[[:space:]]*//'`; a value is "placeholder still there" when empty or starts with `<` (line 62: `case "$v" in ''|'<'*) return 0`). Used for **Approved** (line 124), **Branch** (line 137), **Shipped** (line 223) — NOT for **Checked**, which is read only via `memory/stats/human.jsonl` (lines 200-220). Prints per-line via `say()`(110)/`fail()`(111)/`ok()`(112) as `  01   OPEN  <msg>` or `  01   ok    <msg>`; overall verdict is `READY.` (line 229) or `NOT READY - N open confirmation(s)` (line 231). `--record` (72-98) strips any `**Shipped:** <...>` placeholder line, appends `**Shipped:** $VER, $DATE, at $HEAD[ - $NOTE]` to plan.md (84-89), and appends a JSON row to `memory/stats/ship.jsonl` (93-95): `{ts,spec,version,head,pack,note}`. To accept **Briefed:** as an alternative to **Approved:** at line 124: add `|| [ -n "$(marker "$PLAN" Briefed)" ]` — `marker()` is already generic. To accept **Council:** as an alternative to **Checked:**: since Checked is never marker()-read in ship-check.sh, this needs either a parallel `memory/stats/council.jsonl` block mirroring lines 200-220 (own CLAST/CV/CP/CH lookup, OR'd into the pass/fail), or extending human.jsonl's schema/lookup — a straight `marker()` addition alone won't touch stage-05 logic.

**2. acceptance-log.sh / human-check.sh JSONL schemas.** acceptance-log.sh row (162-164): `{ts, spec, verdict, stories, done, blocked, unrecognised, drift, head, pack, note}` — `drift` is JSON boolean or the string `"unknown"` (159-160) when any story status falls outside todo/in-progress/done/blocked. human-check.sh row (161-162): `{ts, spec, verdict, by, head, pack, note}` — `by` is `git config user.name` or `$USER`/`$USERNAME`/`owner` (131-132). `pack_fingerprint`/`head` as in Key types above. `--check` staleness: acceptance-log.sh (60-89) only compares `pack` (WAS vs NOW) → CURRENT or STALE (no commit dimension). human-check.sh (66-101): first checks verdict≠ACCEPTED→REJECTED; else pack mismatch→"STALE (pack)" (90-93); else if `head` at check-time ≠ current HEAD **and** `paperwork_only()` is false→"STALE (commit)" (95-98); else CURRENT (100). Ledger paths that don't stale a check (paperwork_only whitelist, human-check.sh:56 / ship-check.sh:49, identical): `*/plan.md`, `memory/stats/human.jsonl`, `memory/stats/acceptance.jsonl`, `memory/stats/ship.jsonl`.

**3. state.sh.** Writes gitignored `.claude/state.json` (state.sh:54) from story frontmatter under a target dir (default `docs/specs`), one entry per directory holding ≥1 story file: counts by status, `stale` (a story file's mtime newer than the snapshot, 108-111), and `stage` — a single string built by sequential overwrite (120-131): `01-spec` → `02-planned` (plan.md exists) → `02-approved` (Approved marker) → `03-building` (Branch marker) → `03-built` (no todo/in-progress/unrecognised stories) → `04-tested:<verdict>` (acceptance.jsonl entry for slug) → `05-checked`/`05-rejected` (raw grep of `**Checked:**` line, 119, 127-130) → `06-shipped` (Shipped marker, always last/highest priority, 131). A council stage needs (a) either a `mark()` call on a new "Council" marker or a raw grep like `last_checked`, and (b) insertion into the if-chain at the position matching its intended priority relative to 04/05/06.

**4. wave-check.sh / trace-check.sh.** wave-check.sh parses `wave:`/`blocked_by:` via `fm()` (75-77), `## Files` via `files_of()` (79-87), `## Verification` via `verify_of()` (89-97). Problems: `no-files`(137, empty Files block), `missing`(145, declared path's parent dir absent), `empty-glob`(147, glob matches nothing), `no-verify`(157, empty Verification block), `repeat`(162-163, non-positive-integer `repeat:` value), `verify-gap`(194, verification command's path-like tokens — extracted 172-179, skipping non-existent non-glob tokens so package names/branches/URLs aren't misread — share no `overlap()` with declared Files; silently skipped if the command names no path at all), `dangling`(207, blocked_by id matches no story), `order`(212, blocker's wave not strictly earlier), `collision`(230, two same-wave stories' declared paths overlap via exact/glob/directory-prefix match, `overlap()` 99-109). trace-check.sh: story `## Requirements` blockquotes (65-71) must, after `normalize()` (43: collapse all whitespace incl. newlines to single spaces, trim), appear as a substring of brief.md's joined blockquote text (BRIEF_TEXT, 46) or of plan.md's `## Plan deltas` section (DELTA_TEXT, 52-55, terminated by next `##` heading); miss→`! ... found in NEITHER` (86), delta-only match→`~ ... traces to a plan delta` (83, not a failure). Forward coverage (advisory): each individual brief.md blockquote *line* (BRIEF_LINES, 48-49) checked for bidirectional substring overlap against the concatenation of all story quotes (ALL_QUOTES, 104-114); uncovered lines printed, capped at 12 (128-133).

**5. tests/.** Exactly two files (see Gotchas re: how I confirmed this): `tests/cycle.test.sh` and `tests/handoff-window.test.py`. cycle.test.sh builds a throwaway git repo (12-31): copies real `ship-check.sh`, `human-check.sh`, `acceptance-log.sh`, `redact.sh`, `state.sh` from the source tree, copies `templates/plan.md`, writes one synthetic story (`demo-01-first.md`, frontmatter `story/spec/status/wave`), then walks all 6 stages via `sed` edits to plan.md markers + direct script invocations, asserting exact-substring matches (`expect()`, 16-20, `grep -qF`) on stdout. Assertions that hardcode **Checked:**/human-check.sh specifically and would break if it became optional or renamed to **Council:**: lines 58-59 ("nobody has looked" / "NO HUMAN CHECK RECORDED"), 62-64 (`grep -q '^\*\*Checked:\*\* REJECTED'` directly against plan.md, and the placeholder-gone check), 66-81 (every subsequent STALE(commit)/CURRENT/READY assertion is downstream of `hcheck()`=`human-check.sh --check`), and the fixture copy at line 27 which names `human-check.sh` explicitly. Roughly the back half of the file (stage 05 onward) is coupled to this literal marker/script pair. CI (`ci.yml`): job `cycle` (89-96) runs `bash tests/cycle.test.sh` on `ubuntu-latest` after `actions/checkout@v4`; job `handoff-window` (98-105) runs `python3 tests/handoff-window.test.py .claude/hooks/handoff.py`, same runner. Also present: job `shell` (13-35, shellcheck + `bash -n` over all `*.sh`), job `top-model` (37-87, inline synthetic-profile matrix testing `scripts/top-model.sh` and `.claude/hooks/top-model-brief.sh`, not from a tests/ file), job `install-smoke` (107-153, inline `./install.sh` dry-run/real-run/idempotency checks).

**6. top-model.sh --apply.** (196-236) Resolves MODEL per the normal precedence (env > CLAUDE.md pin > plan signal > opus floor). If `.claude/settings.local.json`'s current `"model"` already equals MODEL, prints "already pinned" and writes nothing (198-201). If the file doesn't exist, writes a fresh minimal file `{"model": "<MODEL>"}` via printf (203-206). If it exists, shells out to whichever of `python3`/`python`/`py` is found, running an inline heredoc (216-230) that loads the JSON (aborts, file untouched, if unparsable/non-dict — exit 4), sets only the top-level `data["model"]` key, and rewrites with `json.dump(..., indent=2)` — preserving every other key (e.g. the owner's `permissions.allow`) untouched. No interpreter found → prints manual-edit instructions and exits 1 without writing anything (211-214).
