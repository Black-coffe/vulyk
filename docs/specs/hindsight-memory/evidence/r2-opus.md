## 3. Anything all three missed

- YouTube_AI still wires `project-learnings.sh` on **SessionEnd** running `claude -p` (`.claude/settings.json` SessionEnd; hook l.40, default on): exactly the anomaly ADR-014 names. It's host-side and out of this study's scope, but it should be reported to that host.
- No proposal measures the post's actual question, "does a filed correction stop repeating". Only C11 comes close; with C3 it gives the one number that matters: repeats after filing, per class, with n.
- The 0.21.1 upgrade shipped a `paths:`-only injector into a host whose whole library uses `area:`, and nothing noticed. C5 catches the symptom, but the upgrade path had no contract check between the shipped hook and the host's cards.
