## 3. What all three missed

1. Plan v2 §1.1 defined `area:` as "маски путей и/или команды"; the build contract renamed that to `paths:` and demoted `area:` to an ignored label — and the pilot's 22 cards were written to the plan's meaning with category words, so the framework hook shipped unable to deliver the very library it was generalised from (#11, #27). C5 is the fix; the missed lesson is that a rename in a contract needs a migration line in the upgrade.
2. `lead-review` runs `defects-check.sh` in audit mode (#28): every new red proposed here (C4, C5, C11) fails a council round, so each must carry the debt rule's new/old-by-blame split or the next upgrade turns the only real host red in review for pre-existing cards.
3. Two counting conventions are live: `defects-check.sh` counts quote lines only under the quotes heading; a file-wide dated-line count (Sonnet's 13/32) includes `## История`. Any new audit line (C4, C5, C11) must reuse the script's heading-scoped parser, or a card's own history will read as owner repeats.
