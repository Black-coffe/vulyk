# Brief - anomaly-telemetry

Date: 2026-09-14 · Owner: Andrei · Deliverable: code · Tier: 3

## Request (verbatim)

> А можешь еще добавить у Vulik где-то так, чтобы не потерялось, чтобы все Cloud Code терминалы, которые будут использовать Vulik, мониторили аномалии, какие-то непонятные вещи, вели файл логирования и раз в неделю отправляли логи в репозиторий Git или тебе в основной проект, если это локальная история. Если это не локальная, а на разных компьютерах, то чтобы отправляли где-то в репозиторий как pull request. С логами про аномалии, но максимально обезличенные, чтобы никто не придрался, что отправляются какие-то личные файлы, а именно контекстные аномалии, перебор по времени, избыточность Vulik, и такие разные вещи. Ты подумай хорошенько, взвесь, как это оцифровать, написать и как это правильно завернуть в фреймворк Vulik. И обязательно об этом нужно в публичном репозитории на GitHub написать, что для улучшения самого Vulik собираются логи, которые вы можете зап ушить как pull request, и раз в неделю будет проводиться очищение тех логов и апдейт самого Vulik для улучшения.

(added 2026-09-14 during planning:)
> При апдейте вулика либо при первой установке нужно, чтобы он в терминале спрашивал у пользователя, хочет ли он включить телеметрию, и объяснить, что это, и сказать, что по умолчанию она выключена.

Context from the same session: three `cycle-clerk` calls cost ~55k tokens each in a hive (constitution 68 KB + 39 KB import); the driver checked out CRLF for two releases and was worked around instead of fixed. Both are the kind of anomaly this spec is meant to catch.

## Answers

1. **Хранение** - memory/stats/anomalies.jsonl, коммитится: та же полка и та же конвенция, что у council.jsonl и human.jsonl: файл в git, еженедельная команда читает его тем же способом, история аномалий видна в истории репозитория. Установщик менять не нужно.
2. **Детекторы** - все пять: контекст сессии выше порога (функция уже есть в handoff.py); субагент дороже N токенов или вернул пусто (читается из его транскрипта); раундов совета больше потолка и стадия дольше бюджета (из journal.md и council.jsonl); отказ или перезапуск драйвера; выход worker'а за скоуп (уже пишется в scope.jsonl).
3. **Отправка** - шаг в /vulyk-evolve, печатает команду: новый шаг собирает обезличенный недельный файл: если репозиторий VULYK лежит на этой машине, кладёт его туда в telemetry/inbox/ и печатает команду коммита; иначе печатает готовую команду gh pr create в публичный репозиторий. Ничего не отправляет само.
4. **Обезличивание** - только коды и числа, хайв как хэш: в строке только код аномалии из фиксированного списка, число, порог, версия VULYK, тир, алиас модели, неделя, и хэш хайва (sha256 от пути, обрезанный, необратимый). Свободного текста в отправляемом файле нет вовсе. Локальный журнал в хайве может держать больше (слаг спеки, имя истории), он никуда не уходит.
5. **Согласие** - строка Telemetry в Профиле, по умолчанию off: новая строка в таблице Profile конституции, /vulyk-bootstrap спрашивает её одним вопросом, установщик дописывает её старым хайвам как off. Журнал пишется всегда, шаг отправки в /vulyk-evolve печатает команду только при on.
6. **Требования** - подтверждаю все пять, план на одобрение.
