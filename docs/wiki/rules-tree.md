# The rules tree (`docs/defects/`)

One library, no second one: `docs/defects/` is the project's rules tree (ADR-021, 0.32.0; amends ADR-014, 018, 019).
Format contract: `docs/defects/README.md`. Mechanics per script: `memory/map/scripts.md`.

- **Layout.** A card is `docs/defects/<id>.md` (area `general`) or `docs/defects/<area>/<id>.md`, one folder level.
  `README.md` and `INDEX.md` are never cards. `id` is the file stem and unique across the library (`DUPLICATE` red).
  VULYK's own cards stay flat.
- **Three branches as sections**, en/ru/uk aliases: Never (`Never|Нельзя|Не можна`), Allowed (`Allowed|Можно|Можна`),
  How-to (`How-to|Как надо|Як треба`). No `kind:` field: a card with a Never or How-to line is prohibitive, with only
  Allowed lines permissive. An Allowed line is dated and in the owner's words; it overrides a Never only through the
  permissive card's `exception: <ref>`, proven by `passes:` fixtures the Never card's `check:` exits 0 on.
- **Scope** stays in `paths:`: globs, `cmd:<regex>`, and `tool:<regex>` (full match on `tool_name`). Narrower
  (more literal characters) wins delivery order, then the freshest quote.
- **One parser.** `.claude/hooks/defects_lib.py` is read by `defects-check.sh`, `defects-index.sh`,
  `defects-inject.sh`, `defect-intake.sh`: no loader is blind to a sub-folder. The gate imports it from the repo's
  own hooks dir, never from `DEFECTS_DIR`.
- **Delivery.** `defects-inject.sh` (PreToolUse on `Edit|Write|MultiEdit|NotebookEdit|Read|Bash|WebFetch|WebSearch|Agent|
  mcp__.*`) shows at most `DEFECTS_INJECT_LINES` (default 12) lines per action and lists the overflow in one line.
  A Read of a story file matches by the story's `## Files` (0.41), so a builder sees the cards before its first edit;
  any other Read leaves in bash. `SubagentStart` was weighed and not used: its input carries no prompt.
  Block-with-check and revoked cards are not injected.
- **Capture.** `defect-intake.sh` hears an explicit "внеси в запрет / правило / разрешение" anywhere (pastes
  included), files typed corrections at once with a report line and "отмени", asks first for a correction inside a
  paste (unless it starts with `$VULYK_DICTATION_TAG`), never counts a side-agent note, and (`answer` mode, PostToolUse
  on `AskUserQuestion`) takes typed text as a quote and a chosen option as a decision.
- **Gate.** Debt is owed only by prohibitive cards; repeated Allowed is an info counter (`allowed repeats`), shown by
  `defects-index.sh --counts` and `/vulyk-status`. Red: `CONFLICT`, `EXCEPTION`, stale `INDEX.md` (generated by
  `scripts/defects-index.sh`; absent = info only).
- **Always-loaded rules** that bind to no file live in `.claude/rules/always.md` (at most 40 lines, capped in
  `tests/maintenance.test.sh`). Lessons about the project go to cards, auto-memory keeps the personal;
  `/vulyk-gc memory` triages private memory into cards / personal / delete (`scripts/memory-triage.sh`).
