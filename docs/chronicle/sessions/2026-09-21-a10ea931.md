# Chronicle location decision and a telemetry.sh bug found

## Decisions
- Session chronicle lives at `docs/chronicle/YYYY-MM.md`, append-only, in its own plugin repo (litopys), not under VULYK's `memory/` and not folded into `docs/specs/<slug>/journal.md` — matches the 2026-09-21 project-memory-chronicle grill's own D2/D3 decisions (distilled+git vs raw+local split; separate plugin so any hive can use it, not just VULYK).

## Problems
- `scripts/telemetry.sh:90` `is_number()` uses a character-class glob (`*[!0-9.-]*`) that accepts malformed numeric shapes like `1.2.3`, `5-3`, `--`, `.`. `cmd_record` (lines 184-185, 201-203) splices `$value`/`$threshold` unquoted into the JSON row after this check, so a malformed value produces invalid JSON in `memory/stats/anomalies.jsonl`, which every downstream `jq` reader (`bundle_emit`, `cmd_check`, `detect_council`) silently drops instead of failing loudly. A fix was proposed as a unified diff (tighter case-based check: optional leading `-`, digits, at most one `.`) but was not applied — left as a proposal only, per instruction not to edit files. Per the Five Laws, applying it should go through a worker once a story exists.

## Brainstorm
- Three candidate homes for the chronicle were weighed: (1) `docs/chronicle/YYYY-MM.md` in its own plugin repo — picked; (2) `memory/` under VULYK's `librarian` — rejected, couples chronicle lifecycle to VULYK-specific memory GC, contradicts grill decision D9 that the chronicle is project-general; (3) folded into `docs/specs/<slug>/journal.md` — rejected, that journal is scoped to one spec's cycle and can't hold conversation happening outside a spec.
